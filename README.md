## 📌 About This Repository

Welcome to **Java Beginner to Expert**! 🚀

This repository is created to document my journey of learning **Java programming** from the very beginning to an advanced level.

Here you will find Java programs, practice questions, concepts, examples, and projects that will help build a strong foundation in Java.

Whether you are a **beginner** or someone who wants to revise Java concepts, this repository will be useful for learning and practicing.

# ▶️ How to Run Java Programs

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/codewithaviiee08/Java_Beginner_to_Expert.git
```

### 2️⃣ Open the Folder

```bash
cd Java_Beginner_to_Expert
```

### 3️⃣ Compile the Java Program

```bash
javac FileName.java
```

### 4️⃣ Run the Program

```bash
java FileName
```

# 🧪 Example

### Java Code

```java
public class Addition {

    public static void main(String[] args) {

        int a = 10;
        int b = 20;

        int sum = a + b;

        System.out.println("Sum = " + sum);
    }
}
```

### Output

```text
Sum = 30
```
